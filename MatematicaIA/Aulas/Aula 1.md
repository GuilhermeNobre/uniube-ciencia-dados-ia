## Função do 1 Grau

**Definição (básica):** Uma função do 1º grau (ou função afim) é uma função que associa a cada número real **x** um número real **f(x)**, seguindo a forma:

$f(x) = m\cdot x + n$

onde **m** e **n** são números reais (constantes) e **m ≠ 0**. (caso m = 0, vira função constante)

1. $f(x) = 2x + 4$ → f(1) = 2.1 + 4 → f(1) =6
2. $f(x) = -4x$ → $f(2) = 8$
3. $f(x) =10x - 10$ → $f(0) = 10.0 - 10$ → $f(0) = -10$

## Coeficientes m, n

M → Cof. Angular

N → Cof. Linear

A função de primeiro de grau sempre é representada por uma reta podendo de ser crescente ou decrescente dependendo do coeficiente angular.

+M → Reta crescente

-M → Reta decrescente
